# Atividade Prática

Atividade prática desenvolvida durante o curso de Power BI, utilizando conexão a um banco de dados MySQL hospedado no Azure e aplicação de transformações de dados no Power Query para carregamento no Power BI Desktop.

### Arquivos

* **Bloco de Notas (.txt):** comandos utilizados no Cloud Shell.
* **Documento Word (.docx):** passo a passo das transformações realizadas no Power Query, com capturas de tela.
* **Arquivo Power BI (.pbix):** projeto com os dados transformados no Power Query.
