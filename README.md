# Curso de Power BI | DIO — Desafios e Projetos

Este repositório reúne os desafios e projetos práticos desenvolvidos durante o curso de Power BI da [DIO](https://www.dio.me/).

## 📚 Projetos desenvolvidos

### 01. Introdução à IA e Agentes

Utilização do NotebookLM como ferramenta de apoio à aprendizagem ativa.

### 02. Fundamentos de BI

Reprodução de duas páginas de um relatório e desenvolvimento de uma terceira página com visualizações de dados, aplicando os conceitos.

**Arquivos disponíveis:**
- **Power BI (.pbix):** arquivo do projeto desenvolvido no Power BI Desktop.
- **Relatório em PDF:** apresentação do relatório e das análises realizadas.

### 03. Visualização de Dados e Relatórios com Power BI

Desenvolvimento de um relatório utilizando a base de dados de exemplo *Financials* do Power BI, explorando recursos visuais para apresentar informações de forma clara e facilitar a análise dos dados.

**Arquivos disponíveis:**
- **Power BI (.pbix):** arquivo do projeto desenvolvido no Power BI Desktop.
- **Relatório em PDF:** apresentação do relatório e das análises realizadas.

### 04. Processamento de Dados com Power BI

Integração de dados de um banco de dados MySQL hospedado no Azure com o Power BI, incluindo a aplicação de transformações no Power Query para preparação e carregamento dos dados.

**Arquivos disponíveis:**
- **Bloco de notas (.txt):** comandos utilizados no Cloud Shell.
- **Documento Word (.docx):** passo a passo das transformações realizadas no Power Query, acompanhado de capturas de tela.
- **Power BI (.pbix):** arquivo do projeto com os dados transformados.

### 05. Modelagem de Dados com Power BI

Desenvolvimento de atividades voltadas à modelagem de dados, explorando a estruturação de modelos dimensionais e a utilização de funções DAX.

**Projetos:**
- **Projeto 1 — Modelagem dimensional:** criação de um diagrama dimensional no formato *Star Schema* (esquema em estrela), com base em um diagrama relacional disponibilizado na atividade.
- **Projeto 2 — Modelagem e transformação de dados:** aplicação de técnicas de modelagem e transformação de dados, utilizando uma tabela de exemplo e funções DAX.

**Arquivos disponíveis:**
- **Imagem (.png):** representação visual do modelo dimensional Star Schema.
- **Power BI (.pbix):** arquivo do projeto com as tabelas, os relacionamentos, as medidas criadas e a tabela calendário desenvolvida com DAX.
- **Documento Word (.docx):** descrição das etapas realizadas e capturas de tela do processo no Power Query.
- **Imagem (.png):** representação visual do modelo dimensional e dos relacionamentos entre as tabelas.

## 🛠️ Ferramentas e tecnologias

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- MySQL
- Microsoft Azure
- NotebookLM
- draw.io

## 📌 Observações

Os projetos foram desenvolvidos como parte do processo de aprendizagem durante o curso. Os arquivos disponibilizados têm como objetivo documentar as atividades realizadas e demonstrar a aplicação prática dos conceitos estudados.

Nos projetos que incluem relatórios em PDF, os arquivos permitem visualizar os resultados sem a necessidade de abrir o Power BI Desktop.

A publicação no Power BI Service não foi realizada nas atividades em que seria necessária uma conta corporativa ou educacional, pois disponho de uma conta pessoal. Por esse motivo, os arquivos dos projetos são disponibilizados neste repositório para consulta.
